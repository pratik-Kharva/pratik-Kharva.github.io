Before this goes live

Please read

This is a demo dashboard. All data is stored locally in this browser using localStorage — nothing is sent anywhere, nothing is shared between devices, and there is no login. Clearing your browser data deletes it.

A production deployment requires a secure backend, authenticated admin accounts with roles, a real database, server-side validation, audit logging and encrypted backups. Do not use this build to run the business.
